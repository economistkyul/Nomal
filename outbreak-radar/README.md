# 감염병 확산 레이더

질병관리청 감시자료로 **어느 감염병이, 어느 연령대·시도에서 확산 초기인지** 보는 화면입니다.

- 보기: https://economistkyul.github.io/Nomal/outbreak-radar/
- 화면: 질병별 현황 카드(8종) · 시도 타일 지도(영유아 독감) · 연령대별 독감 막대 · 항목별 추이 차트

## 자료가 들어오는 방식

GitHub Actions(`.github/workflows/outbreak-radar-update.yml`)가 **매일 10:17, 18:17(한국시간)** `scripts/update.mjs`를 실행합니다. 새 값이 있으면 `data/sentinel.json`에 주차별로 덧붙여 커밋하고, 화면은 열 때마다 이 파일의 최신본을 읽습니다.

| 출처 | 가져오는 것 | 질병청 발표 |
|---|---|---|
| 감염병포털 「감염병 표본감시 주간소식지」 | 독감 의사환자·입원·검출률, 코로나19 입원·검출률, 급성호흡기감염증·중증 입원, RSV·리노·메타뉴모·마이코플라스마 입원(비중×전체 추정), 장관감염증·노로(추정), 수족구 | 매주 목요일 |
| 질병청 인플루엔자 보도자료 | 연령별(7구간) 독감 의사환자 분율 | 대개 금요일 |
| 시도별 요약(육아크루가 질병청 시도 자료를 정리한 페이지) | 시도별 0–6세 독감 의사환자 분율 | 매주 |

질병청 발표가 주 1회라 값이 실제로 바뀌는 날은 주 1~2회입니다. 화면 맨 위에 마지막 자동 갱신 시각과 출처별 성공(✓)/실패(✗)가 나옵니다.

## 직접 실행 · 문제가 생겼을 때

- 저장소 → Actions → 「감염병 확산 레이더 자료 갱신」 → Run workflow 로 바로 실행할 수 있습니다.
- 주간소식지 목록을 못 읽으면(✗) 감염병포털에서 해당 주 소식지 글을 열고, 그 주소를 Run workflow의 `kdca_url`에 붙여 넣으면 됩니다.
- 질병청이 문장 형식을 바꾸면 `scripts/parse.mjs`의 정규식을 고치고 `npm test`로 확인합니다(테스트는 실제 소식지 문장으로 작성됨).
- 시도별 수집을 끄려면 `skip_regional`에 1.

## 판정 규칙(detect.js)

| 단계 | 조건 |
|---|---|
| 확산 초기 | 2주 이상 연속 증가 + 주간 증가율 8% 이상 + 아직 낮은 수준(기준 고점의 50% 미만, 기준이 없으면 상승 3주 이내) |
| 초기 신호 | 1주 증가(+8% 이상) — 한 주 더 확인 필요 |
| 확산 중 / 정점·둔화 / 보합 / 감소 | 높은 수준에서 증가 / 증가세 꺾임 / 주간 −5~+8% / −5% 이하 |

## 한계

- 시도별 값은 질병청 원자료가 아닌 정리본을 거칩니다. 전국 값을 시도 값처럼 보여 주는 페이지는 자동으로 거르고, 세종·제주·전남광주는 비어 있을 수 있습니다.
- RSV·마이코플라스마·노로 수는 소식지의 '전체 × 원인 비중'으로 만든 추정치이고, 비중이 상위 3위 밖이면 그 주는 비어 있습니다.
- 참고 지표이며 질병청 공식 판정(유행주의보 등)을 대신하지 않습니다.

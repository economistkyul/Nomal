# 지금 세종 교통 (1단계 시제품)

세종 도로가 지금 어디서 막히는지 색으로 한눈에 보여주는 웹 지도입니다. 출근·퇴근 전에 휴대폰으로 열어 보는 용도로 만들었습니다.

- **실시간 혼잡 색상 지도**: 초록 원활 · 노랑 서행 · 빨강 정체 (카카오맵 실시간 교통정보). 5분마다 자동 새로고침.
- **바로가기**: 정부세종청사 · 2청사 · 세종시청 · 오송역 · 조치원 · 대전 방면(반석역), **내 사무실**(청사 동별, 기기에 기억).
- **교통 CCTV**: 지도 위 카메라를 누르면 실시간 영상 (국토교통부 국가교통정보센터, 고속도로·국도).
- **내 위치**, 출퇴근 시간대 표시, 링크 공유.

## 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 전체. 맨 위 `REGIONS`에 지역·바로가기·사무실 좌표가 있습니다 |
| `api/config.js` | 화면에 카카오 지도 키와 CCTV 사용 여부를 알려주는 서버 함수 |
| `api/cctv.js` | ITS 인증키로 CCTV 목록을 대신 불러오는 서버 함수(키는 화면에 노출되지 않음, 1분 캐시) |
| `manifest.webmanifest` | 홈 화면에 추가(앱처럼 쓰기)용 |

## 배포하기 (Vercel)

이 폴더는 `Nomal` 저장소 안의 `sejong-traffic/` 폴더입니다.

1. [vercel.com](https://vercel.com) → **Add New… → Project** → `Nomal` 저장소 **Import**.
2. **Root Directory**를 `sejong-traffic`로 바꾸고 **Deploy**. → `https://<프로젝트이름>.vercel.app` 주소가 생깁니다.
3. 아직 키가 없어서 화면에 "지도 키 설정이 필요해요"가 나오면 정상입니다. 아래 키 설정을 하세요.

## 키 설정

### ① 카카오 지도 키 (필수)

1. [developers.kakao.com](https://developers.kakao.com) → 내 애플리케이션 → **애플리케이션 추가하기** (앱 이름 예: 지금 세종 교통).
2. 앱 설정에서 **[카카오맵] → 사용 설정 → 상태 ON**.
   - 2026년 7월 21일부터 카카오맵 무료 사용량은 **개발자 계정에서 처음 카카오맵을 켠 앱 하나에만** 줍니다. 이 앱이 처음이면 무료로 쓸 수 있습니다.
   - 지도 사용량은 화면을 열 때 1회만 셉니다(지도를 움직이거나 확대해도 늘지 않음).
3. **[플랫폼] → Web → 사이트 도메인**에 Vercel 주소(`https://<프로젝트이름>.vercel.app`)를 등록.
4. **[앱 키]**의 **JavaScript 키**를 복사.
5. Vercel 프로젝트 → **Settings → Environment Variables** → 이름 `KAKAO_JS_KEY`, 값에 붙여넣기 → 저장.
6. **Deployments** → 가장 최근 배포의 ⋯ → **Redeploy**.

### ② CCTV 키 (선택)

1. [ITS 국가교통정보센터](https://www.its.go.kr) 회원가입 → **공공데이터 개방 → 오픈API** → CCTV 화상자료 **인증키 신청**. 승인되면 마이페이지에서 키를 확인합니다.
2. Vercel 환경변수에 `ITS_API_KEY`로 넣고 **Redeploy**.
3. CCTV가 안 뜨면 `https://<주소>/api/cctv?debug=1`을 열어 ITS가 돌려준 메시지를 확인하세요(키는 가려서 보여줍니다).

참고: ITS CCTV는 고속도로·국도 카메라입니다. 세종 시내 도로 카메라는 거의 없습니다.

## 쓰는 법

- 주소 뒤에 `#sejong@osong`처럼 붙이면 그 위치로 바로 열립니다. 바로가기 코드: `gov1`(정부세종청사), `gov2`(2청사), `cityhall`, `osong`, `jochiwon`, `daejeon`, 사무실 `b1`~`b17`, `bc`(중앙동).
- 휴대폰에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 다른 지역 늘리기

`index.html` 위쪽 `REGIONS`에 지역을 하나 더 넣으면 됩니다. 예:

```js
daejeon: {
  name: '대전', center: [36.3504, 127.3845], level: 7,
  spots: [ { id: 'gov', t: '정부대전청사', lat: 36.3590, lng: 127.3830, lv: 4 } ],
  offices: []
}
```

`https://<주소>/#daejeon`으로 열면 됩니다. 색상 지도·CCTV 모두 전국 데이터라 지역을 늘려도 따로 설정할 것이 없습니다. (좌표는 지도에서 확인 후 넣어 주세요.)

## 알아둘 점

- 참고용 정보이며 운전 중 조작하지 않도록 안내하고 있습니다.
- 개인이 공개 데이터로 만든 서비스이며 정부·지자체의 공식 서비스가 아닙니다(화면 안내에 표시).
- 카카오 API 결과는 저장할 수 없어(카카오 약관) 시간대별 통계는 2·3단계에서 공공 데이터로 따로 만듭니다.
- 바로가기 좌표(오송역·조치원·반석역·세종시청)는 대략값입니다. 어긋나면 `REGIONS`에서 고치세요. 청사 동별 좌표는 '오늘 뭐 먹지'와 같습니다.

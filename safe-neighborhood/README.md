# 우리동네 안심 체크 — 기획서

> 우리 동네에 **신상공개 대상 성범죄자가 몇 명** 등록돼 있는지 지역 단위 숫자로 쉽게 보여주고,
> 개인 확인이 필요하면 공식 창구(성범죄자알림e)로 바로 연결하는 웹 페이지입니다.
> 누가·어디에 사는지는 **표시하지 않습니다.**

---

## 1. 왜 만드나

- 성범죄자알림e는 개인별 신상 확인에는 충실하지만, "우리 동·구가 다른 곳과 비교해 어느 정도인가"를 한눈에 보기는 어렵습니다.
- 반대로 개인 신상을 캡처해 단톡방·카페에 올리는 일은 선의라도 **형사처벌 대상**입니다.
- 그래서 **집계 숫자는 쉽게, 개인 정보는 공식 창구에서만** 확인하도록 역할을 나눕니다.

## 2. 법적 경계 (설계의 출발점)

| 구분 | 내용 | 이 프로그램의 처리 |
|---|---|---|
| 청소년성보호법 제55조 | 공개정보는 성범죄 우려자 **확인 목적으로만** 사용, 출판물·방송·**정보통신망으로 재공개 금지** | 성명·주소·사진·죄명 등 개인 항목을 **수집·저장·표시하지 않음** |
| 같은 법 제65조 | 제55조 위반 시 5년 이하 징역 또는 5천만원 이하 벌금 | 화면에 경고 문구 상시 표시 |
| 전자장치(전자발찌) 위치 | 법무부 위치추적관제센터만 관리, **일반에 비공개** | 위치·명단 기능 없음. 전국 규모 통계와 확인 경로만 안내 |
| 사적 제재 우려 | 알림e도 이름 검색 없이 지도·지역 단위로만 조회 | 최소 단위를 **읍·면·동 인원수**로 제한 |

- 데이터 수집 스크립트는 지역명·인원수 외 필드를 **허용목록(whitelist) 방식으로 버립니다.** 원본에 개인 항목이 섞여 있어도 저장되지 않습니다.
- 이 저장소는 법률 자문이 아닙니다. 운영·배포 전 소관 부처(성평등가족부) 또는 법률 전문가 확인을 권장합니다.

## 3. 데이터

| 데이터 | 출처 | 비고 |
|---|---|---|
| 지역별 공개고지 대상 등록 현황(시도·구군·읍면동별 개수) | 공공데이터포털, 성평등가족부 「성범죄자 신상정보 공개고지 관리 주요시도상태 정보」(OpenAPI, 이용허락범위 제한 없음) | `scripts/fetch_counts.py`로 수집 → `data/counts.json` |
| 전자감독 대상자 전국 규모 | e-나라지표 「특정 범죄자 위치추적 현황」(법무부) | 지역별 수치는 공개되지 않음 |

> ⚠️ 공공데이터포털 API의 정확한 요청주소·응답 항목명은 **활용신청 후 상세화면에서 확인**해 설정해야 합니다(아래 4-2).
> `counts.json`이 없으면 페이지는 **가상의 지역명으로 된 예시 데이터**를 띄우고, 상단에 "예시 데이터" 배너를 표시합니다.

## 4. 사용법

### 4-1. 바로 보기
`index.html`을 브라우저로 열거나 GitHub Pages 주소로 접속합니다.
데이터가 없을 땐 예시 화면이 나오며, **CSV 불러오기** 버튼으로 직접 내려받은 통계 파일(시도·시군구·읍면동·개수 열)을 넣어 볼 수 있습니다. 불러온 파일은 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다.

### 4-2. 실제 데이터 넣기
1. [공공데이터포털](https://www.data.go.kr)에서 "성범죄자 신상정보 공개고지 관리 주요시도상태 정보" 검색 → 활용신청(자동승인)
2. 상세화면의 **요청주소**와 발급받은 **일반 인증키(Decoding)** 확인
3. 실행 (Python 3.8+, 추가 설치 불필요)

```bash
export DATA_GO_KR_KEY="발급받은_인증키"
export SEXOFFENDER_API_URL="상세화면의_요청주소"
python3 scripts/fetch_counts.py --basis-date 2026-11-01
```

응답 항목명이 예상과 다르면 직접 지정합니다.

```bash
python3 scripts/fetch_counts.py --map sido=ctpvNm,sgg=sggNm,emd=emdNm,count=regCnt
```

CSV로 받은 경우:

```bash
python3 scripts/fetch_counts.py --csv 내려받은파일.csv --basis-date 2026-11-01
```

4. 생성된 `data/counts.json`을 커밋하면 페이지에 반영됩니다.

## 5. 화면 구성

1. **지역 선택** — 시도 → 시군구 → 읍면동 순 선택, 동 이름 검색
2. **결과 카드** — 선택 지역 등록 인원, 상위 지역 합계, 같은 상위 지역 내 평균과 비교
3. **비교 막대** — 같은 단계의 지역들을 인원순으로 나열하고 선택 지역 강조
4. **개인 확인은 공식 창구로** — 성범죄자알림e 연결 + 재배포 처벌 경고
5. **전자발찌 안내** — 위치 비공개 사유, 알림e의 '전자장치 부착 여부' 항목, 전국 통계 경로
6. **도움 받기** — 112, 여성긴급전화 1366

## 6. 해석 시 주의 (화면에도 표시)

- 숫자는 **법원이 공개명령을 내린 사람**만 집계합니다. 모든 성범죄 전과자 수가 아닙니다.
- 등록 인원이 많다고 그 지역이 더 위험하다는 뜻은 아닙니다. 인구 규모, 교정시설·보호시설 위치 등에 따라 달라집니다.
- 0명이어도 "안전 보장"을 뜻하지 않습니다.
